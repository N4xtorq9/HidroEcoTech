# 🌱 HidroEcoTech

**HidroEcoTech** es un proyecto web dedicado a explorar y presentar información sobre las energías renovables, con especial atención a la energía hidroeléctrica en Colombia.

## 📌 Descripción

El proyecto reúne contenido informativo sobre distintas fuentes de energía renovable y ofrece una estructura web para consultar sus características.

## ⚡ Secciones principales

- 💧 **Energía hidroeléctrica:** información sobre la generación de energía a partir del agua.
- 🌬️ **Energía eólica:** introducción al aprovechamiento del viento.
- ☀️ **Energía solar:** información sobre el uso de la radiación solar.

## 🛠️ Tecnologías y herramientas

- **HTML** para la estructura de las páginas.
- **CSS y recursos gráficos** para la presentación visual.
- **JavaScript** para funcionalidades del sitio.
- **Visual Studio / .NET** para la solución y el proyecto de API incluidos en el repositorio.
- **Prepros** para la configuración de procesamiento de recursos web.

## 📂 Estructura del proyecto

```
HidroEcoTech/
├── assets/                 # Recursos del sitio
├── MiFormularioAPI/         # Proyecto de API
├── index.html               # Página principal
├── hidroelectrica.html      # Sección de energía hidroeléctrica
├── eolica.html              # Sección de energía eólica
├── solar.html               # Sección de energía solar
├── HidroEcoTech.sln         # Solución para Visual Studio
└── prepros-6.config         # Configuración de Prepros
```

## 🚀 Cómo ejecutar el sitio web

1. Clona el repositorio:
   
   ```
   git clone https://github.com/N4xtorq9/HidroEcoTech.git
   ```
   
2. Entra en la carpeta del proyecto:
   
   ```
   cd HidroEcoTech
   ```
   
3. Abre `index.html` directamente en el navegador o utiliza **Live Server** desde Visual Studio Code.
   

### Proyecto de API

El repositorio también contiene la carpeta `MiFormularioAPI` y la solución `HidroEcoTech.sln`. Para revisar o ejecutar esa parte, abre la solución con Visual Studio y verifica la configuración y los requisitos definidos por el proyecto.

## 🎯 Objetivo

Promover la exploración y el conocimiento de las energías renovables mediante una plataforma web informativa.
